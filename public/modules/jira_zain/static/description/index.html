🎯 Jira-Zain

Agile Project Management for Odoo 16 - Like Jira and Trello combined!

Features

📋 Kanban Board

Visual task management with drag & drop. Move tasks through stages: Backlog → To Do → In Progress → Review → Done

🏃 Sprint Management

Plan and execute sprints with start/end dates, sprint goals, and velocity tracking.

🎲 Story Points

Estimate task complexity with story points. Track team velocity across sprints.

⏱️ Time Logging

Track time spent on tasks. See planned vs actual hours.

👥 Scrum Roles

Built-in security groups: Product Owner, Scrum Master, Project Manager, Team Member

Task Types

  • 📋 Task - General work item
  • 🐛 Bug - Something to fix
  • ✨ Feature - New functionality
  • 📈 Improvement - Enhancement

Installation

  1. Copy this folder to your Odoo addons directory
  2. Restart Odoo server
  3. Go to Apps → Update Apps List
  4. Search for "Jira-Zain" and install
